
# Array Categories Examples

This repository provides examples for the four categories of arrays based on memory allocation strategies, in both C++ and Python:

### 1. Fixed Stack-Dynamic
- C++: Array size is fixed at compile time.
- Python: Fixed list initialized with known values.

### 2. Stack-Dynamic
- C++: Array size determined at runtime, stack-allocated.
- Python: List created with runtime size input.

### 3. Fixed Heap-Dynamic
- C++: Dynamic allocation with `new`, size fixed after allocation.
- Python: List comprehension based on user input (conceptual equivalence).

### 4. Heap-Dynamic
- C++: Heap array resized manually by allocating new memory.
- Python: List resized using `append()` method.

Each example demonstrates how arrays are declared and managed based on these categories.

## How to Use
1. Compile and run C++ files using a C++ compiler (e.g., `g++`).
2. Run Python files using Python 3.

Feel free to clone and explore!
